Product Dashboard
Description

This project is a product dashboard built using vanilla JavaScript, HTML, and CSS. It displays and manages product-related data in a simple and organized interface, simulating a real-world business dashboard.

Features
Display product data in a structured layout
Dynamic updates using JavaScript
Clean and simple dashboard interface
Organized data presentation
Technologies Used
JavaScript (Vanilla)
HTML
CSS
How to Run
Clone or download the repository
Open the project folder
Open index.html in your browser

Structuring and displaying data in a dashboard format
Improving UI layout with HTML and CSS
